# Codex 额度悬浮窗

一个适用于 Windows 的 Codex 额度桌面悬浮窗。安装后会读取当前用户本机的 Codex 会话记录，显示剩余额度和重置时间；不需要 API 密钥，也不会上传额度数据。

## 下载与安装

前往 [Releases](../../releases/latest)，下载 `CodexQuotaWidget-Setup-x64.exe`，双击安装即可。普通用户只需要下载这个 `.exe` 文件；发布页自动附带的两个 Source code 压缩包是源码快照，不用于安装。

安装不需要管理员权限。完成后可以从桌面或开始菜单打开“Codex 额度悬浮窗”。

## 功能

- 悬浮显示 Codex 剩余额度和预计重置时间。
- 内置极简、盘香、钓鱼、抱石、猫线团 5 套皮肤，可在浮窗中切换。
- 支持浅色和深色主题。
- 浮窗可拖动，并会记住所选皮肤和主题。
- 只读取当前 Windows 用户的本机 Codex 数据。

如果暂时没有额度信息，请先在 Codex 中进行一次对话，再重新打开或刷新浮窗。

## 支持范围

- Windows 10 / 11
- x64 电脑

## 发布维护

向 `main` 推送会自动构建安装包供测试。创建 `v*` 版本标签后，GitHub Actions 会自动发布正式安装包。
