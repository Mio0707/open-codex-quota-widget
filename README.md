# Open Codex Quota Widget · 浮游猫音乐皮肤

这是基于 `open-codex-quota-widget v1.1.1` 恢复并扩展的版本。原有皮肤保持不变，新增了音乐联动的**猫脸水母**皮肤。

## 直接体验

运行 `dist/CodexQuotaWidget.exe` 即可直接进入猫脸水母皮肤。也可以点击浮窗右上角的皮肤按钮切换其他皮肤。

## 联动方式

- 整体音量：呼吸幅度和亮度
- 低频与节拍：身体柔软回弹
- 中频：水母裙摆和身体游动
- 高频：轮廓发光和少量浮游光点
- 没有声音：保持安静、缓慢的漂浮动画

程序读取 Windows 当前默认输出设备上的全部电脑声音，因此不依赖 QQ 音乐或其他播放器接口，也不需要登录。声音只在内存中实时分析，不录音、不写入磁盘。

## 构建

运行 `build.ps1`。脚本会优先使用工作区里的便携 .NET 8 SDK，也支持系统已安装的 .NET 8 SDK。成品输出到 `dist`。

项目源码位于 `app`，恢复自上游 v1.1.1 的成品程序，并已重新整理为可编译工程。
